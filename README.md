# fraismensuels-cli

Neon CLI client for the Frais Mensuels webapp.

## Setup

1) Install deps
- `npm install`

2) Configure base URL (required)
- `FRAISMENSUELS_BASE_URL=https://your-app-domain`

3) Run
- `npm run dev`

## Commands

- `fraismensuels` — launch interactive TUI
- `fraismensuels logout` — clear session
